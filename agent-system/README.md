## BRIDGE procedures

Delivery work uses `.agents/skills` (`to-spec` → `to-tickets` → `implement` → `tdd` → `code-review`) and GitHub Issues. Architect owns orchestration, design delegation (`architecture-engineer`), review findings (`code-review-engineer` / `/architect-review`), and Close cleanup.

## Operate layout

| Path | Purpose |
|---|---|
| `handoffs/active/<task-id>/` | Thin YAML/MD handoffs while work is live |
| `handoffs/archive/<task-id>/summary.yaml` | Short record after Close |
| `scratch/<task-id>/` | Disposable probes/builds (deleted on Close) |
| `protocols/task-close.yaml` | Close checklist |

`scratch/` and `handoffs/active/` are gitignored (see `.gitignore`).
